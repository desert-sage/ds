# @ds-lang/tools

The tools for Desert Sage (DS): the `ds` command, which is dsdb, the DS debugger.

## Contents

`ds` and its subcommands `ds test`, `ds lsp`, `ds dap` and `ds mcp`, on `@ds-lang/ds`. `@ds-lang/ds` is bundled, with the DS compiler and the DS standard library. The package runs wherever Node runs.

## Install

```sh
npm install @ds-lang/tools
```

`ds` is installed at `node_modules/.bin/ds`. It runs on Node 20 or later, and needs nothing else installed, no `dsc` included.
