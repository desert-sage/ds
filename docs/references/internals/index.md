# The DS Internals Reference

## Desert Sage

DS is the short form of Desert Sage.

*(Spec: [LSCO.1.13])*

## What this book covers

This book covers the engine's mechanism, the artefact and wire formats, the atom registry, and complexity.

## Covered elsewhere

The DS language as written, and the tools an author runs, are [The DS Author's Reference](inv:author:std:doc#index). The libds C API, which is also the C binding, is [The DS Integrator's Reference](inv:integrator:std:doc#index). The Python, JavaScript and Mercury bindings are [The DS Bindings Reference](inv:bindings:std:doc#index). The normative definition of DS is [The DS Specifications](inv:specs:std:doc#README).

## Reading an entry

An entry is a signature or syntax, a one-sentence definition, its behaviour, at most one fragment, and a citation. A citation names a clause, written `[LEXP.7.13.1]`, which links to it, a `.proto` file, or a shipped source file.
