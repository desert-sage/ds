# The DS Integrator's Reference

## Desert Sage

DS is the short form of Desert Sage.

*(Spec: [LSCO.1.13])*

## What this book covers

This book covers the libds C API, which is also the C binding: every public symbol in `libds.h`, ownership and lifetimes, threading, callbacks, results and error codes, and the rules a C caller follows.

## Covered elsewhere

The DS language as written, and the tools an author runs, are [The DS Author's Reference](inv:author:std:doc#index). The Python, JavaScript and Mercury bindings are [The DS Bindings Reference](inv:bindings:std:doc#index). The engine's mechanism, the artefact and wire formats, the atom registry and complexity are [The DS Internals Reference](inv:internals:std:doc#index). The normative definition of DS is [The DS Specifications](inv:specs:std:doc#README).

## Installing

Installing begins at [Header and linking](conventions/linking.md).

## Reading an entry

An entry is a signature or syntax, a one-sentence definition, its behaviour, at most one fragment, and a citation. A citation names a clause, written `[LEXP.7.13.1]`, which links to it, `libds.h` and its symbol, a shipped source file, or a release asset.
