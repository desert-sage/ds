# @ds-lang/ds

The JavaScript binding to libds, the rule engine of Desert Sage (DS).

## Contents

libds built for wasm32, the DS compiler `ds_dsc`, and the DS standard library, with `@emnapi/runtime` bundled. The package has no native target.

## Install

```sh
npm install @ds-lang/ds
```

It runs on Node 20 or later, and needs nothing else installed.

## Reference

The API is [The DS Bindings Reference](https://ds-lang.org/docs/latest/bindings/index.html).
